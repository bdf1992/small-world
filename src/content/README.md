# Content

Content owns authored Definitions, Templates, and References expressed through the plain model contract.

M0.6 initial content:

- Personas: Bandit, Bear, Dragon
- Biomes: Swamp, Desert, Mountains
- Items: Sword, Staff, Shield
- Packs: Cave, Ruin, Spire
- Instruments: Clock, Hourglass

Content may declare Sections, Slots, Regions, Attributes, Properties, Stats, Rules, priors, affinities, ranges, and relationships.

Content must not implement solver traversal, random-number policy, graph propagation, or runtime commit behavior.
