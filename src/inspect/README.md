# Inspection

Inspection explains the generative system without becoming part of the solver's authority.

M0.6 inspection modes:

- **Facts** — committed Instance state.
- **Possibilities** — current Virtual candidates, ranges, and unresolved slots.
- **Lineage** — Definition → Template → Reference → Virtual → Instance ancestry and causes.
- **Signals** — optional engineering-level propagation/collapse trace.

The same inspection surface should eventually support designer authoring, debugging, player inspection, and replay explanation at different levels of detail.
